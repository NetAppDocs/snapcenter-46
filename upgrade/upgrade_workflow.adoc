= Upgrade workflow
:icons: font
:imagesdir: ../media/

[.lead]
Each release of SnapCenter contains an updated SnapCenter Server and plug-in package. Plug-in package updates are distributed with the SnapCenter installer. You can configure SnapCenter to check for available updates.

The workflow shows the different tasks required to upgrade the SnapCenter Server and the Plug-in packages.

image::../media/upgrade_workflow.png[]

[NOTE] 
========
* SnapCenter supports direct upgrades only along the paths shown in the table above. If you need to upgrade to a version that is not directly supported from your current version, you must perform a series of incremental upgrades. For example, if you are on SnapCenter version 4.3.x and want to upgrade to 4.6.x, you should first upgrade to 4.5.x and then do a rolling upgrade to 4.6.x. This approach ensures compatibility between versions and prevents issues that can occur when skipping intermediate releases. Always verify the supported upgrade path in the table before beginning your upgrade.

* For information about upgrading the SnapCenter Plug-in for VMware vSphere, see link:https://docs.netapp.com/us-en/sc-plugin-vmware-vsphere/scpivs44_upgrade.html[Upgrade SnapCenter Plug-in for VMware vSphere^]
